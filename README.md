# 我的面板 — Personal Dashboard

一个极简的个人目标进度追踪页面。

## ✨ 功能

- 💰 显示当前余额（手动更新）
- 🎯 设置目标金额，看进度
- 📈 自动记录每次更新的历史
- 🌙 赛博暗黑风
- 📱 PC / 移动端适配
- 💾 数据存浏览器 localStorage（不上云）

## 🚀 开发

```bash
pnpm install
pnpm dev          # 启动开发服务器 → http://localhost:5174
pnpm build        # 构建生产版本
pnpm preview      # 预览构建产物
```

## 🛠 技术栈

- Vue 3 + Vite 5
- Tailwind CSS 3
- 纯前端，零后端

## 📝 使用说明

1. 打开页面，点击余额卡片右上角的 ✏️ 按钮，输入当前余额
2. 点击「⚙️ 设置目标」，定一个金额目标
3. 后续每次想看进度，打开支付宝瞄一眼，回来更新一下数字即可
4. 历史记录会自动保留最近 50 次更新

## ⚠️ 关于支付宝接口

支付宝**不开放给个人用户的余额查询接口**。这个工具用最朴实的"手动更新数字"方式，
代价是每次要打开支付宝看一眼，但好处是：
- 零依赖
- 零隐私风险
- 0 成本，且永远不会因为接口政策变化而失效
